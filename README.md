# Trilinear Infratech – Brochure Website (Angular)

This is a starter Angular (standalone components) website built from the brochure structure:
Home, About, Services, Projects, Approach, Clients, Contact.

## Prereqs
- Node.js 18+ (recommended 20+)
- Angular CLI 20+

## Run
```bash
npm install
npm start
```

Then open: http://localhost:4200

## Assets
Brochure pages were exported to `src/assets/brochure/` as PNGs. Replace/add higher-quality images anytime.
